## 桌面入口

新增 `Open-LifeOS.vbs` 和 `scripts/Launch-LifeOS.ps1`，由 `scripts/Install-DesktopShortcut.ps1` 创建用户桌面的 `LifeOS.lnk`。

双击快捷方式静默调用已有启动程序，保持同一本机地址、专用浏览器配置和 JSON 保存位置。启动脚本用命名互斥锁防止同时启动多个本机服务。每次启动日志独立保存，避免快速双击争用同一日志。

实测快捷方式返回 0，正常打开应用；重复启动前后的本机服务 PID 一致，正确复用已有服务。冷启动时正确建立本机服务。关闭页面不会主动停止服务；重启电脑后需要再次双击快捷方式。未配置开机自启或另建复盘定时任务。

个人任务/成长数据、浏览器配置、运行日志和本机测试产物不属于仓库上传内容。
