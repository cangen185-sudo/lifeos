# V0.1 已拍板决策

开发节奏由作者决定，不按原 PRD 日历排期。产品边界仍以这些决定为准。

- 形态：可安装 PWA；中文界面；手机底栏、桌面侧栏式导航。
- 数据：本机 IndexedDB；不做云同步；提供 JSON 导出/导入。
- 干预：关闭时不催；打开/聚焦时再算。系统 Push 不做。
- 最小 MVP：本人录入欲望和今日任务；一个任务可手动关联多个欲望，目标与承诺可选。旧任务的 Goal → Desire 关联继续显示。
- Today 可先于 Direction：MUST 可以没有 Goal；新任务不再按标题擅自建立关联，按已确认欲望的重要程度排序高亮。
- Commitment 结案：只提示 at-risk，由用户手动确认。
- 剩余时间：`min(容量剩余, 到当天 23:59)`；MUST 可以没有开始时间。
- 当前最小 MVP 不做 Project、任务依赖、Graph 页、LLM、画像、账号、后台推送；先验证手动录入与多对多关联。
